# RX 590 GME

Polaris 20, GCN 4.0, 14 nm. 2304 shaders, 256-bit GDDR5, 8GB. Sold in some markets as a 590 while the silicon is the 580's Polaris 20, not the 12 nm Polaris 30 of the original RX 590. For this studio the practical limits are the same: 8GB, no ROCm, Vulkan for LLMs, DirectML fp32 for SD 1.5.

PCI ID `6fdf` is Polaris 30 (RX 590). `67df` is the Ellesmere family and covers 4GB and 8GB boards. If detection is ambiguous, the studio assumes 8GB and says so. Change it in Settings if the card is a 4GB 570/580.

## Drivers

Use the Adrenalin package AMD still lists for the RX 590. A newer package that "auto adjusts" and then fails to load Polaris is a known way to get code 43 and random black screens. If the card artifacts after a driver update, roll back one version with DDU rather than stacking installs.

## Do not force ROCm

`HSA_OVERRIDE_GFX_VERSION=8.0.3` is how people get this card to pretend it is supported. It is also how training and llama.cpp die with a GPU reset and a desktop flicker. Leave it unset. Ollama: `OLLAMA_VULKAN=1` before the server starts. llama.cpp: a Vulkan build, `-ngl 99` only when the Models page says the weights fit.

## Windows timeout

`TdrDelay` defaults to 2 seconds. An SD 1.5 step on this card is often longer. The process disappears. Python has no traceback because the driver killed the device.

`scripts/Check-Rx590.ps1` reads the key. `scripts/Enable-LongGPUTimeout.reg` sets it to 60. Reboot. This does not fix a bad overclock. If you see artifacts, lower clocks; do not raise TDR further.

## Heat and power

The GME runs hot. Raise the fan curve before the power limit. A thermal throttle here often ends as a driver reset, which the watchdog will resume, but the checkpoint cannot save a card that is artifacting.

## Memory

- Close hardware-accelerated browsers while training. Chrome can hold 0.5–1GB of this VRAM.
- Pagefile 32GB on Windows. A commit-charge kill looks random.
- 16GB system RAM is the comfortable floor for caching latents. 8GB system RAM will swap and look like a stall.

## What fits

| Job | Fits | Does not |
| --- | --- | --- |
| LLM | 7B/8B Q4_K_M, context clamped (often ~8k, not 32k/128k) | 14B Q4 with a long context, FP16 7B |
| Train | SD 1.5 LoRA, 512, rank 8–16, fp32, batch 1 | SDXL, 768 training, fp16 DirectML |
| Generate | SD 1.5 at 512 or 512×768 via Forge DirectML | 1024, hires fix, SDXL |

The Models page is the source of the context number. Do not copy a model card's "128k" into Ollama on this machine.
