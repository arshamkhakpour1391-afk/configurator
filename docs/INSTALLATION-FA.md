# راهنمای نصب MobiCare (قدم‌به‌قدم، غیرتوسعه‌دهنده)

این راهنما فرض می‌کند هاست وردپرس (cPanel / DirectAdmin / Plesk) دارید.

---

## مرحله A — وردپرس

1. وردپرس را نصب کنید (یک‌کلیک هاست یا دستی).
2. وارد `/wp-admin` شوید با کاربر مدیر.
3. **تنظیمات → عمومی**: عنوان سایت (مثلاً نام فروشگاه)، زبان **فارسی**.
4. **تنظیمات → پیوندهای یکتا**: «نام نوشته» را انتخاب و ذخیره کنید (برای URL تمیز محصولات).

---

## مرحله B — ووکامرس

1. **افزونه‌ها → افزودن** → WooCommerce → نصب → فعال.
2. ویزارد را کامل کنید یا بعداً از **ووکامرس → تنظیمات**.
3. برگه‌ها باید ساخته شوند:
   - فروشگاه (Shop)
   - سبد خرید (Cart)
   - تسویه‌حساب (Checkout)
   - حساب کاربری (My account)
4. اگر برگه‌ها نیست: **ووکامرس → وضعیت → ابزارها → ایجاد برگه‌های پیش‌فرض ووکامرس**.

### تنظیمات کلیدی

**عمومی**

- آدرس فروشگاه: ایران
- واحد پول: تومان (IRT) یا ریال
- موقعیت مشتری پیش‌فرض: کشور فروشگاه

**ارسال**

- افزودن منطقه «ایران»
- روش: نرخ ثابت / رایگان بالای مبلغ X / تحویل محلی

**پرداخت**

- درگاه بانکی واقعی را نصب و پیکربندی کنید
- تا قبل از اتصال درگاه، می‌توانید «پرداخت هنگام تحویل» را برای تست داخلی روشن کنید
- **هرگز** اطلاعات API درگاه را در قالب/کد قرار ندهید — فقط در تنظیمات افزونه درگاه

**حساب‌ها و حریم خصوصی**

- ☑️ اجازه به مشتریان برای ساخت حساب در برگه «حساب من»
- ☑️ اجازه ورود با ایمیل
- ورود = **ایمیل + رمز عبور** (بدون کد تأیید اجباری به ایمیل، مگر افزونه جدا نصب کنید)
- برگه حریم خصوصی را مشخص کنید

## مرحله C — آپلود قالب و افزونه

### روش ۱: File Manager / FTP

```
public_html/wp-content/themes/mobicare/     ← تمام فایل‌های theme/mobicare
public_html/wp-content/plugins/mobicare-core/  ← تمام فایل‌های plugins/mobicare-core
```

### روش ۲: زیپ

1. داخل پوشه `mobicare` (جایی که `style.css` هست) همه فایل‌ها را زیپ کنید → `mobicare-theme.zip`
2. **نمایش → پوسته‌ها → افزودن → بارگذاری پوسته**
3. پوشه `mobicare-core` را زیپ کنید → **افزونه‌ها → افزودن → بارگذاری**

### فعال‌سازی

1. پوسته‌ها → **MobiCare** → فعال
2. افزونه‌ها → **MobiCare Core** → فعال
3. صفحه **MobiCare → راه‌اندازی** را باز کنید و چک‌لیست را طی کنید

---

## مرحله D — پیکربندی ظاهر

1. **نمایش → سفارشی‌سازی**
2. هویت سایت: لوگو + عنوان
3. **تنظیمات MobiCare**:
   - تماس و شبکه‌های اجتماعی
   - نوار اعلان (مثلاً «ارسال رایگان بالای …»)
   - هیرو
   - بنرهای تبلیغاتی (تصویر + لینک)
   - FAQ
   - رنگ اصلی
4. **نمایش → فهرست‌ها**
   - یک فهرست بسازید: خانه، فروشگاه، دسته‌ها، تماس
   - نمایش در موقعیت: منوی اصلی + منوی موبایل + فوتر

---

## مرحله E — داده کسب‌وکار (بدون محصول假)

1. برند گوشی و مدل گوشی
2. دسته‌بندی‌ها
3. محصولات واقعی شما
4. کوپن‌ها در صورت نیاز
5. هزینه ارسال

تا وقتی محصول اضافه نکنید، بخش‌های «ویژه / جدید / تخفیف» در صفحه اصلی **خالی و مخفی** می‌مانند (عمدی).

## مشکلات رایج

| مشکل | راه‌حل |
|------|--------|
| صفحه سفید | PHP 8+، حافظه 256M، خطا را در `wp-content/debug.log` ببینید (موقتاً WP_DEBUG) |
| استایل به‌هم | کش مرورگر/افزونه کش را خالی کنید |
| برگه سبد ۴۰۴ | پیوند یکتا را دوباره ذخیره کنید |
| مدل گوشی در انتخابگر نیست | مدل را به برند وصل کنید (فیلد برند در ویرایش مدل) |
| درگاه نیست | افزونه درگاه را جدا نصب کنید |

---

## امنیت تولید

- رمز مدیر قوی + احراز هویت دوعاملی در صورت امکان
- به‌روزرسانی منظم WP / WC / PHP
- محدود کردن `wp-admin` با IP در صورت نیاز
- پشتیبان روزانه
