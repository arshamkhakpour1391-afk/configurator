قالب فروشگاهی ووکامرس فارسی RTL برای قاب گوشی و گلس.

== Description ==

MobiCare یک قالب پریمیوم فروشگاهی سازگار با WooCommerce است:
* فارسی و راست‌چین
* دارک مود
* انتخابگر مدل گوشی
* بهینه‌سازی موبایل
* بدون محصول نمونه

نیازمند افزونه MobiCare Core و WooCommerce.

== Installation ==

1. پوشه mobicare را در wp-content/themes قرار دهید
2. افزونه mobicare-core را فعال کنید
3. WooCommerce را نصب کنید
4. پوسته را فعال کنید
